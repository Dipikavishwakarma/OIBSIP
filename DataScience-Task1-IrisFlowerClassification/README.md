# Task 1: Iris Flower Classification

## Overview
This project is part of the Oasis Infobyte Data Science Internship. The goal is to train a machine learning model to classify iris flowers into three species (Setosa, Versicolor, Virginica) based on sepal and petal measurements.

## Dataset
- **Source:** `sklearn.datasets.load_iris()`

## Tech Stack
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-Learn

## Models Trained & Results
- **Logistic Regression Accuracy:** ~100%
- **K-Nearest Neighbors Accuracy:** ~100%
